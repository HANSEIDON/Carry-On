# Carry On — 설계서 v1.0

> 비행으로 집중하고, 캐리어에 스티커로 쌓는다.
> 백색소음 + 점점 쌓여가는 성취감이 핵심 경험.

- 확정일: 2026-10-20
- 앱 내 언어: 영어 (안내방송 포함) / 문서: 한국어

---

## 1. 플랫폼 & 기술

| 구분 | 선택 | 비고 |
|---|---|---|
| 코어 | React + TypeScript + Vite | 코드 1벌로 전 플랫폼 |
| 상태 / 저장 | Zustand / Dexie (IndexedDB) | 로컬 우선 |
| 동기화 | Supabase (Auth + Postgres) | 게스트로 시작 → 원할 때 로그인. Google + Apple 로그인 |
| Android / iOS | Capacitor | 네이티브 플러그인: 백그라운드 오디오, 포그라운드 서비스, 라이브 업데이트, 햅틱 |
| Windows | PWA (설치형, 추후 MS Store via PWABuilder) | 필요 시 Tauri로 교체 가능 |
| 지도 | d3-geo + Natural Earth 벡터 지구본 | 오프라인, 스타일 선택 |
| 3D | Three.js (react-three-fiber) | 캐리어 화면에서만 사용 |
| 사운드 | Web Audio API | 기내 소음은 실시간 합성, 안내방송은 녹음 조각 이어붙이기 |

**플랫폼 우선순위**: Web(개발) → Android + Windows → iOS(개발자 계정 결제 후, 클라우드 빌드)

**테스트 방법** (개발자가 아이폰 사용자)
- 평소: PC 브라우저
- 아이폰 확인: 같은 Wi-Fi에서 `npm run dev:lan` → Safari 접속 / 이후 웹 배포(Vercel 등) URL
- 네이티브 기능: Android Studio 에뮬레이터
- 실제 iOS 앱: Apple Developer Program($99/년) + 클라우드 빌드 → TestFlight

## 2. 핵심 루프

```
예약 → 체크인(좌석) → 탑승권 → 스텁 뜯기(=시작) → 이륙 방송
→ 순항 = 집중 (백색소음) → 착륙 → 캐리어에 스티커 부착 → 마일 적립
→ 면세점에서 새 캐리어 구매 → 다음 비행은 도착지에서 출발
```

## 3. 비행 시스템

### 3.1 비행 시간 = 실제 거리 기반
- `비행 시간(분) = 대권거리(km) / 800 × 60 + 30` → 5분 단위 반올림
- 예: 서울-부산 55분, 서울-제주 1시간 5분, 서울-베이징 1시간 40분, 서울-도쿄 2시간, 서울-런던 11시간 35분, 서울-뉴욕 14시간 20분
- 긴 비행은 중간에 기내식 휴식이 들어가므로 하루 공부 = 장거리 비행 하나로 쓸 수 있음

### 3.2 예약 방법 2가지
1. **목적지 먼저**: 출발지 + 목적지 → 시간 자동 계산
2. **시간 먼저**: 출발지 + 원하는 시간 → 그 시간 ±10%(최소 ±10분) 안의 도시 목록

### 3.3 출발지
- 기본값 = 마지막 도착지 (세계일주처럼 이어짐)
- 자유롭게 변경 가능

### 3.4 관광 비행 (Scenic flight)
- 짧은 집중(45분 이하)용. 출발 도시로 되돌아오는 원형 경로
- 예: "Seoul Han River Scenic Flight"

### 3.5 쉬는 시간
- **기내식 서비스**: 긴 비행 중간 휴식. "We'll now begin our meal service" 방송 → 휴식 → 안전벨트 사인 다시 켜짐
- **경유 라운지**: 뽀모도로처럼 끊어서 가는 경우, 경유지 공항 라운지 앰비언스
- Gold 이상: 라운지 화면 업그레이드

### 3.5.1 기내 소음 설계 원칙 (2026-10-20)
- 실제 순항 기내: 동체 표면 난류 경계층 소음이 주성분, 에너지는 저중역(약 200–400Hz)에 집중, 앞쪽은 얇고 밝게·뒤쪽은 두껍고 낮게
- 불쾌감을 키우는 요소 회피 (심리음향): 순음(tonality), 날카로움(sharpness), 거칠기·요동(roughness/fluctuation), 반복·이음매
- 구현: 실시간 핑크 노이즈 → 저중역 몸통 + 통풍구 공기 + 협대역 엔진 드론, 30초 이상의 느린 레벨 변화만
- **기종 음색**: 실제 순항 녹음(A320·737·777)의 시간축 중앙값 스펙트럼으로 만든 필터로 실시간 노이즈를 깎음 → 실제 기종 음색, 반복·말소리·아기 소리 없음. 협동체 노선은 A320/737, 광동체·장거리는 777
- 바이노럴 비트: 근거가 엇갈리고(2019 메타분석 g=0.45, 2023 리뷰는 동조 기전에 엇갈림) 스피커에선 거친 울림이 되므로 **기본 꺼짐, 헤드폰 전용 옵션**
- 백색/핑크 노이즈의 집중 효과는 ADHD군에서만 소폭(2024 메타분석 g≈0.25), 비ADHD군은 오히려 저하 → 효과를 과장하지 않고 볼륨을 사용자 조절로
- **집중 모드** (기본 꺼짐): 160Hz 로우셸프 -7dB로 저음 웅웅거림을 더 줄임 (80–160Hz 약 -3.5~-6.6dB, 320Hz 이상은 거의 그대로). 저주파 소음은 같은 dBA여도 고난도 과제 수행을 떨어뜨리고 더 피로하게 함 (Persson Waye 외)
- **비행 중 소리 조작은 최소한만**: 화면에는 볼륨 슬라이더 하나와 'Sound settings' 버튼만. 방송·안전벨트 차임·집중 모드·바이노럴 톤은 설정 패널 안에

### 3.6 체크인: 여행 목적 & 좌석
- 여행 목적 선택: Study / Work / Reading / Creative / Other → 탑승권·비행 기록에 남고, 나중에 여권 통계에 사용 (FocusFlight 참고)
- 좌석 선택 화면 (실제 항공사 좌석 배치도 참고: 클래스 구역, 통로, 날개, 비상구, 이미 찬 좌석, "Assign for me")
- 화면 흐름은 Flighty처럼 단계별로 필요한 것만: Check-in → Boarding → In flight → Arrived
- 좌석 위치별 백색소음 차이: 앞쪽 = 조용한 바람소리 / 날개 = 묵직한 엔진음 / 뒤쪽 = 큰 엔진음
- 좌석 등급: Economy / Business / First (회원 등급으로 해금, First는 더 조용함)

### 3.7 기종 & 항공사
- 기종은 거리 기준: 단거리 A320/737급, 중거리 787/A330급, 장거리 A350/777급
- 항공사는 **국가별 가상 항공사** (실제 항공사 이름/로고 금지 — 상표 문제)

### 3.8 안내방송 (영어) — 대본 확정 (2026-10-20)
- 화자 2명: **승무원**(환영·도착·휴식) / **기장**(이륙·순항·하강·착륙·안전벨트). 실제 비행의 역할 분담
- 톤: 실제 항공사 문구 + 은근한 집중 넛지 ("set your phone to flight mode", "enjoy the quiet")
- 대본 원본: `src/domain/announcements.ts` (문구를 바꾸면 음성 클립 재생성 필요)

| # | 시점 | 화자 | 차임 | 문구 ({ }는 가변) |
|---|---|---|---|---|
| 1 | 스텁 뜯은 직후 | 승무원 | 2음 | Ladies and gentlemen, welcome aboard {Hanul Air} flight {four seven four} to {Tokyo}. Our flight time today is {two hours}. Please fasten your seatbelt, and set your phone to flight mode. |
| 2 | 1 직후 | 기장 | 1음 | Cabin crew, please prepare for take-off. |
| 3 | 순항 고도 도달 | 기장 | 2음 | Good {afternoon} from the flight deck. We've reached our cruising altitude of {thirty-five thousand} feet, and the seatbelt sign is now off. We'll have you in {Tokyo} in about {one hour and thirty minutes}. Sit back, and enjoy the quiet. |
| 4 | 하강 시작 | 기장 | 2음 | Ladies and gentlemen, we've begun our descent into {Tokyo}. We expect to land in about {twenty minutes}. Please return to your seat and fasten your seatbelt. |
| 5 | 착륙 8분 전 (짧은 비행은 하강의 절반) | 기장 | 1음 | Cabin crew, please take your seats for landing. |
| 6 | 도착 화면 | 승무원 | 2음 | Ladies and gentlemen, welcome to {Tokyo}. The local time is {two thirteen p.m.} Thank you for flying {Hanul Air}. |
| 8 | 휴식 시작 (휴식 기능 구현 시) | 승무원 | 2음 | Ladies and gentlemen, we'll shortly begin our meal service. Feel free to stretch, and take a short break. |
| 9 | 휴식 종료 / 난기류 (90분 이상 비행의 약 1/3, 1회) | 기장 | 1음 | Ladies and gentlemen, the seatbelt sign has been switched on. Please return to your seats, and fasten your seatbelt. |

- 관광 비행: 1 "welcome aboard this {airline} scenic flight over {Seoul}. We'll be in the air for about {…}" / 3 "cruising at {six thousand} feet over {Seoul}" / 4 "we'll shortly begin our approach back into {Seoul}" / 6 "welcome back to {Seoul}"
- 회항(중도 종료) 방송은 넣지 않음
- 음성 (2026-10-21 선택): 기장 = Chatterbox `cb-default`·`cb-george` (편명별로 둘 중 한 명, 같은 편은 같은 기장), 승무원 = Kokoro `alice-112` (Alice 1.12배속)
- **구절 클립**: 방송을 쉼표·마침표에서 끊긴 구절로 나눠 구절마다 클립 1개를 미리 생성(`docs/VOICE_CLIPS.md`). 도시·항공사·편명·시간은 늘 구절 통째로 → 단어 중간 이음매 없음. 이음매를 위해 쉼표 추가: "welcome aboard Hanul Air, flight four seven four, to Tokyo.", "We'll have you in Tokyo, in about …"
- 클립 수를 줄이려고: 남은 시간은 2시간부터 15분 단위로 반올림, 도착 현지 시각은 5분 단위 (14:13 → "two fifteen p.m.")
- 재생: 구절 사이 쉼표 0.14초·문장 0.24초(승무원)/0.36초(기장), 기내 PA 필터(`cabin`), 클립이 없으면 기기 음성으로 대체
- **방송 중에도 기내 소리는 그대로** (실제 비행처럼): 기내 소리와 방송·차임은 버스와 리미터를 따로 써서 방송이 기내 소리를 끌어내리지 않음
- 볼륨: 슬라이더 하나. 방송은 기내 볼륨의 **고정 비율**(`ANNOUNCEMENT_SHARE` 0.35)로 따라가 늘 기내 소리 아래에 거슬리지 않게 깔림 (2026-10-21 0.75 → 0.5 → 0.35). 차임도 같은 PA 버스를 탐. 방송 끄기 옵션
- 방송 볼륨 (2026-10-24): 소리 설정 안 'Announcement volume' 슬라이더로 다시 조절 가능. 기본값은 귀로 맞춘 그 비율(0.35, 슬라이더 가운데에 표시), 0~2배까지, 'Default'로 한 번에 복귀. 비행 화면 밖 간단 조작은 그대로 볼륨 하나
- 목소리 크기 맞춤: 클립은 같은 음량(약 -20dB)으로 만들지만 PA 스피커가 저음을 깎아 남자 목소리가 작게 들림 → PA 체인을 통과시킨 뒤 귀 가중(BS.1770 K-weighting)으로 재서 기장 +1.2dB(cb-default)·+1.4dB(cb-george) 보정(전체 클립에서 고르게 40개씩 측정). 클립 없는 구절의 기기 음성도 클립과 같은 높이로(×2.6)

### 3.9 엄격 모드 (기본 ON)
- **모바일**: 앱을 벗어나면 1분 유예 → 초과 시 **회항(Diverted)**, 보상 없음
  - 화면 끄기(잠금)는 이탈 아님
  - 전화 수신은 예외
  - 유예 중 표시: 헤드업 알림 + 카운트다운, Android 16+ 라이브 업데이트(상태바 칩)
  - 옵션: "다른 앱 위에 표시" 권한으로 플로팅 알약 (다이나믹 아일랜드 느낌)
  - iOS: Live Activity + Dynamic Island (iOS 단계에서)
- **Windows**: 창 전환은 허용. 앱 종료/비행 포기만 회항
- 일시정지 모드는 옵션

### 3.10 비행 중 표시

## 5. 보상: 스티커

### 5.1 종류 (실제 공항 기준)
| 종류 | 획득 |
|---|---|
| 수하물 태그 스텁 (감열지, 목적지 코드, 바코드, 태그번호) | 매 비행 기본 보상 |
| 손잡이 루프 태그 | 최근 비행 1개만 손잡이에 걸림. 다음 비행 시 제거, 몸통엔 스텁만 남음 |
| Priority / First | 비즈니스·퍼스트석 또는 Gold 이상 |
| 보안검색 스티커 | 국가별 언어/디자인 (예: 已安检, 検査済) |
| Transfer | 경유 비행 |
| Fragile / Heavy | 랜덤 레어 |

### 5.2 실사 표현
- 레이어: 디자인(코드/바코드/띠) + 실사 재질(CC0 종이·구김·때) + 3D 요철/광택 맵
- **에이징**: 오래된 스티커는 바래고, 귀퉁이 찢어지고, 떼어진 자국이 남음
- 3D 캐리어 위에 **데칼**로 투영 → 조명 받아 감열지 광택이 보임
- 실제 항공사 태그 사진/로고 사용 금지. 공항 IATA 코드는 실제 코드 사용

- 방향 보정: 이미지→3D 결과는 원본 사진의 비스듬한 카메라를 따라 기울고 돌아가 있음 → 모델마다 `orient`(pitch·yaw·roll)로 바로 세우고 앞면을 정면으로 (`src/data/carriers.ts`). 자동 수평(바운딩 상자 부피 최소) + 앞면은 눈으로 90° 단위 선택. 009는 사진에서 부엉이가 정면을 보는 쪽(yaw 53)
- 화면: 홈(사용 중 캐리어 3D는 보기만 — 이름·문구·조작 없이 예약 버튼 하나, 앱의 중심은 집중), 보관함(도감 30칸 중 누른 것이 위 무대에: 내 것은 3D, 못 찾은 것은 실루엣 + 면세점 바로 가기, 안 만든 것은 ?, 채운 캐리어들도 골라 봄), 면세점(화살표 없음. 위 진열대는 손가락으로 돌려 보기, 아래 사진 칩 줄을 스와이프해 넘기고 탭하면 바뀜, 보관함에서 오면 그 상품부터)

### 6.1.1 스티커 (2026-10-22, 같은 날 개정)
- 착륙 때 받은 스티커는 사용 중인 캐리어의 3D 표면에 **데칼로 투영**해 붙음: 표면을 따라 붙고 3D와 같이 돌아감. 도착 화면에도 같은 그림
- **목적지 여행 라벨** (매 착륙): 나라마다 다른 빈티지 러기지 라벨 — 국가 43곳별 모양(원·타원·방패·사각), 국기에서 따온 색·배치·모티프(일본 붉은 원, 한국 태극, 프랑스 세로 삼색, 스위스 십자, 터키 초승달…). **국기는 늘 온전히** — 라벨 위쪽에 국기, 그 아래(방패는 위쪽)에 크림색 띠로 도시명과 국가·공항·편명·날짜. 띠가 국기를 가로지르거나 모양이 국기를 잘라 찢긴 듯 보이는 디자인은 쓰지 않음
- **PRIORITY** (비즈니스·퍼스트, 또는 골드 이상)
- **취급 스티커** (착륙의 30%, 비행마다 고정): FRAGILE 40% · SCREENED 30% · HEAVY 20%(2시간 이상 비행, 아니면 FRAGILE) · TRANSFER 10%(6시간 이상, 아니면 SCREENED)
- **붙는 자리는 넓은 면만**: 모델마다 스티커 자리를 미리 계산(`src/data/carrierSlots.json`) — 기울기 35° 이내의 판판한 면, 손잡이·바퀴·걸쇠·모서리 제외. 앞면 가운데서 바깥으로 자라는 무리, 이웃과 살짝만(최대 14%) 겹침, 앞 → 오른쪽 → 왼쪽 → 위 → 뒤 순
- 크기: 스티커 자리는 캐리어 긴 변의 14% × 7%(2:1). 여행 라벨이 꽉 차고, 취급 스티커는 그 50~76%. 판판한 곳이 좁은 캐리어(로봇)는 0.8·0.65배
- 스티커마다 시드 고정된 약간의 기울기(±8°)와 어긋남. 새 스티커가 위에 겹치고, 오래된 것일수록 종이가 누렇게

### 6.1.2 용량과 채우기 보상 (2026-10-22)
- 용량 = 그 캐리어의 스티커 자리 수, 최대 40 (대부분의 가방·트렁크 40, 스쿠터 37, 로켓 16, 로봇 9~11)
- 다 채우면: 그 캐리어는 스티커 그대로 보관함에 남고(“✓ No. 1 · 날짜”), 같은 종류의 새 캐리어(스티커 없음, No. 2…)가 바로 사용 중이 됨. 계속 반복해서 쌓을 수 있음
- 채우기 마일: **스티커 자리당 30마일, 그 종류를 처음 채우면 2배** (예: 기본 쉘 40칸 첫 완성 2,400 · 이후 1,200)
  - 근거: 컬렉션 게임의 세트 완성 보상처럼 '쫓을 만하지만 비행을 대신하진 않는' 크기. 기본 회원(비행당 라벨 1장 + 가끔 취급 스티커, ~400마일) 기준 채우는 동안 번 마일의 10% 미만, 첫 완성은 약 1/6
  - 자리당이라 큰 캐리어든 작은 로봇이든 비행당 보상은 같음(작은 걸 빨리 돌리는 꼼수 없음). 골드·플래티넘은 비행당 스티커 2장이라 두 배 빨리 채움 = 등급 혜택
  - 처음 2배 = 처음 깨는 보상(first clear). 기본 쉘 첫 완성 ≈ 기본 등급 캐리어 한 개 값 → 첫 목표로 자연스럽게 면세점에 이어짐
  - 채우기 마일은 쓸 수 있는 마일에만 (등급용 누적 마일은 비행한 만큼만)
- 착륙 화면에 "Carrier full" 카드(보너스, 처음이면 'first time · double')

## 7. 경제: 마일리지 & 면세점

- 마일 = 비행 거리 (km × 0.621). 집중 1시간 ≈ 350~500마일
- 관광 비행: 분당 5마일
- **면세점 (Duty Free)**: 마일로 캐리어 구매. 3D 회전 진열대. 회원 등급으로 해금, 가격은 등급별(기본 2,500 / 실버 6,000 / 골드 15,000 / 플래티넘 30,000마일), 같은 캐리어는 하나씩. 두 번 탭해서 구매
  - 도시 한정: 현재 위치가 그 도시일 때만 구매 가능
  - 등급 한정 / 시즌 한정
- 가격 기준(초안): 일반 5,000 / 고급 20,000 / 전설 100,000
- 가챠 없음, 현금 결제 없음

### 9.1 여권 (2026-10-21)
- 닫힌 여권: 세로 표지. 국적에 따라 색과 자국어 이름이 바뀜(한국 청록, 일본·중국 적색, 유럽 버건디, 미국·영국 남색…). 가죽 결, 형압 테두리, 금박 글자, 실제 국가 문장 대신 가상 문장(지구·궤도·비행기), 전자여권 칩 마크
- 실사 질감 (2026-10-22, 2D 유지): 왼쪽 위 조명을 받은 가죽 결(SVG 조명 필터, 이미지 파일 없음), 가장자리가 둥글게 말린 가죽(반짝이는 빛 효과는 넣었다가 뺌). 닫힌 책자는 표지 아래로 종이 단면과 뒤표지가 비치고 그림자. 표지는 종이보다 조금 커서 펼치면 가죽 테두리(넘어가는 표지도 같은 크기라 여닫을 때 가장자리에 아무것도 생겼다 사라지지 않음), 종이 묶음 단면, 철 쪽으로 휘어 어두워지는 골. 종이엔 결과 색 보안 섬유
- 조작: 스와이프·탭, 머리글 오른쪽 모서리 Close. 화살표·'Data page' 같은 설명 문구 없이 아래엔 점만(펼침면이 많으면 얇은 진행선)
- 열기: 표지를 탭하면 ① 책자가 옆으로 눕는 90° 회전과 함께 카메라가 물러나듯 작아져 펼침 크기에 맞춰지고 ② 이어서 표지가 철 위로 넘어가며 펼쳐짐 → 실제 출입국 심사대처럼 철이 가운데 가로로 놓인 위·아래 두 면(각 면 가로 125×88). 첫 펼침면은 위 = 표지 안쪽, 아래 = 데이터 면
- 넘기기: 종이처럼 아래 면이 손가락을 따라 들리며 철 위로 넘어감(위·옆 스와이프). 놓을 때 1/3 넘었거나 빠르게 튕기면 넘어가고 아니면 되돌아옴. 탭하면 한 장. 첫 펼침면에서 뒤로 넘기거나 닫기 버튼 = 표지가 내려와 덮인 뒤 책자가 다시 세로로 섬. 종이 소리와 표지 소리, 짧은 진동
- 이 화면의 움직임은 기기의 '모션 줄이기'가 켜져 있어도 재생(짧고, 사용자의 탭·스와이프로만 시작)
- 데이터 면: 사진(직접 선택, 35:45로 잘라 기기에만 저장) + 고스트 이미지, 성·이름·국적·발급/만료일·발급 기관(Carry On Airways · 등급), 서명, 키네그램 띠, 손가락 따라 움직이는 라미네이트 홀로그램, ICAO 9303 MRZ(검증 숫자까지 실제 규칙)
- 편집: 시트 맨 위에 데이터 면 미리보기, 입력하는 즉시 여권에도 반영, 저장하면 확정·취소하면 되돌림
- 배서 면: 타자기 글씨 비행 기록(비행 수·집중 시간·국가·도시·마일·최다 방문·최장·목적별 시간·회항) + 멤버십 인장
- 사증 면: 착륙한 비행마다 도장(면당 3열×2행 6개). 국경을 넘으면 출국국 출국 도장 + 도착국 입국 도장, 국내·관광 비행은 Carry On 도장. 나라별 모양·잉크·문구·날짜 표기(예: 한국 타원 "입국 ARRIVAL", 일본 사각 "上陸許可 ADMITTED", 솅겐 별 고리 + 화살표). 조금씩 비뚤게, 잉크 번짐
- 이름을 바꾸면 인사말과 탑승권 승객명(`HAN/SEIDON`)도 같이 바뀜

## 10. 디자인

- **첫 사용자 가이드 (2026-10-22)**: 처음 열면 홈 위에 카드 4장 — 집중 = 비행 / 끝까지 탑승(일찍 끝내면 회항) / 착륙하면 여권 도장·나라별 라벨 / 마일로 면세점, 캐리어 채우기. Skip 가능, 한 번만
- **예약 화면 첫 진입 안내**: 조작 하나씩 밝혀 4단계(출발지 바꾸기 → 집중 시간 → Surprise me → 도시 고르고 Check in), Skip 가능, 한 번만. 홈 가이드는 개념, 이건 조작
- **팁**: 둥근 카드 + 전구 배지. 예약 화면에 아주 가끔 한 줄(하루 최대 하나, 그때도 방문의 약 1/3). 출발지 바꾸기, Surprise me, 나라별 라벨, 캐리어 채우기, 좌석 소리, 지도 스타일, 다크 모드, 집중 모드. 안 본 것부터
- **Surprise me** (예약 > 시간별): 대부분 1~2시간만 집중해서 집 근처 몇 곳만 가게 되는 걸 풀어 줌 — 고른 시간쯤의 비행을 세계 어디서든 출발하는 노선 중 무작위로 고르고 출발지도 거기로. 4번 중 3번은 아직 착륙해 보지 않은 나라

- **다크 모드 (2026-10-22)**: Auto(기기 설정 따라, 기본)·Light·Dark. 여권 화면 머리글 오른쪽 해/달 버튼에서 선택. 다크는 '밤의 노트' — 따뜻한 검은 종이, 밝은 잉크, 더 밝은 도장 빨강. 여권·탑승권·수하물 태그·종이 지도 같은 실물은 어두운 책상 위 종이처럼 원래 색 유지
- **비행 지도**: Paper(기본)·Classic(낮의 파랑·모래색, 노란 경로)·Night(어두운 지구, 빛나는 해안선과 도시 불빛). 지도 색은 앱 테마와 무관, 공항 코드는 밝은 글자 + 어두운 테두리로 어디서나 읽힘
- **좌석 배치도**: 위에서 본 비행기 모양 — 길고 뾰족한 기수(레이돔 이음선, 잉크색 조종석 창 6장 — 색·빛 효과 없이)와 바로 뒤에서 시작하는 객실(앞 빈 공간 없음), 여백을 둔 채 전체적으로 키운 비행기와 좌석, 날개 위 줄 옆 빗금 날개 뿌리, 둥근 꼬리 끝 (스웹트 날개·테이퍼 꼬리는 써 봤다가 원래대로)

- **앱 UI**: 다크 미니멀 (실제 항공사 앱 / 기내 모니터 느낌)
- **수집품** (캐리어, 스티커, 지도): 실사
- 폰트: Inter (UI), Barlow Condensed (코드/태그), Roboto Mono (편명/태그번호)
- 앱 아이콘: 추후 생성

| 단계 | 내용 |
|---|---|
| **1. 웹 핵심** | 프로젝트 세팅, 도시 DB, 예약/시간 계산, 탑승권+뜯기, 비행 화면(지도), 사운드, 착륙 보상, 로컬 저장 → 아이폰 Safari 확인 |

| 4. 계정 | Supabase 로그인 & 동기화 |
| 5. iOS & 출시 | 개발자 계정, Live Activity, 앱 아이콘, 스토어 출시 |
