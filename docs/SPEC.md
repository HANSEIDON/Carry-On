# Carry On — 설계서 v1.0

> 비행으로 집중하고, 캐리어에 스티커로 쌓는다.
> 백색소음 + 점점 쌓여가는 성취감이 핵심 경험.

- 확정일: 2026-10-20
- 앱 내 언어: 영어 (안내방송 포함) / 문서: 한국어

---

## 1. 플랫폼 & 기술

| 구분 | 선택 | 비고 |
|---|---|---|
| 코어 | React + TypeScript + Vite | 코드 1벌로 전 플랫폼 |
| 상태 / 저장 | Zustand / Dexie (IndexedDB) | 로컬 우선 |
| 동기화 | Supabase (Auth + Postgres) | 게스트로 시작 → 원할 때 로그인. Google + Apple 로그인 |
| Android / iOS | Capacitor | 네이티브 플러그인: 백그라운드 오디오, 포그라운드 서비스, 라이브 업데이트, 햅틱 |
| Windows | PWA (설치형, 추후 MS Store via PWABuilder) | 필요 시 Tauri로 교체 가능 |
| 지도 | d3-geo + NASA Blue/Black Marble | 2D, 오프라인 |
| 3D | Three.js (react-three-fiber) | 캐리어 화면에서만 사용 |
| 사운드 | Web Audio API | 기내 소음은 실시간 합성, 안내방송은 녹음 조각 이어붙이기 |

**플랫폼 우선순위**: Web(개발) → Android + Windows → iOS(개발자 계정 결제 후, 클라우드 빌드)

**테스트 방법** (개발자가 아이폰 사용자)
- 평소: PC 브라우저
- 아이폰 확인: 같은 Wi-Fi에서 `npm run dev:lan` → Safari 접속 / 이후 웹 배포(Vercel 등) URL
- 네이티브 기능: Android Studio 에뮬레이터
- 실제 iOS 앱: Apple Developer Program($99/년) + 클라우드 빌드 → TestFlight

## 2. 핵심 루프

```
예약 → 체크인(좌석) → 탑승권 → 스텁 뜯기(=시작) → 이륙 방송
→ 순항 = 집중 (백색소음) → 착륙 → 캐리어에 스티커 부착 → 마일 적립
→ 면세점에서 새 캐리어 구매 → 다음 비행은 도착지에서 출발
```

## 3. 비행 시스템

### 3.1 비행 시간 = 실제 거리 기반
- `비행 시간(분) = 대권거리(km) / 800 × 60 + 30` → 5분 단위 반올림
- 예: 서울-부산 55분, 서울-제주 1시간 5분, 서울-베이징 1시간 40분, 서울-도쿄 2시간, 서울-런던 11시간 35분, 서울-뉴욕 14시간 20분
- 긴 비행은 중간에 기내식 휴식이 들어가므로 하루 공부 = 장거리 비행 하나로 쓸 수 있음

### 3.2 예약 방법 2가지
1. **목적지 먼저**: 출발지 + 목적지 → 시간 자동 계산
2. **시간 먼저**: 출발지 + 원하는 시간 → 그 시간 ±10%(최소 ±10분) 안의 도시 목록

### 3.3 출발지
- 기본값 = 마지막 도착지 (세계일주처럼 이어짐)
- 자유롭게 변경 가능

### 3.4 관광 비행 (Scenic flight)
- 짧은 집중(45분 이하)용. 출발 도시로 되돌아오는 원형 경로
- 예: "Seoul Han River Scenic Flight"

### 3.5 쉬는 시간
- **기내식 서비스**: 긴 비행 중간 휴식. "We'll now begin our meal service" 방송 → 휴식 → 안전벨트 사인 다시 켜짐
- **경유 라운지**: 뽀모도로처럼 끊어서 가는 경우, 경유지 공항 라운지 앰비언스
- Gold 이상: 라운지 화면 업그레이드

### 3.6 체크인: 여행 목적 & 좌석
- 여행 목적 선택: Study / Work / Reading / Creative / Other → 탑승권·비행 기록에 남고, 나중에 여권 통계에 사용 (FocusFlight 참고)
- 좌석 선택 화면 (실제 항공사 좌석 배치도 참고: 클래스 구역, 통로, 날개, 비상구, 이미 찬 좌석, "Assign for me")
- 화면 흐름은 Flighty처럼 단계별로 필요한 것만: Check-in → Boarding → In flight → Arrived
- 좌석 위치별 백색소음 차이: 앞쪽 = 조용한 바람소리 / 날개 = 묵직한 엔진음 / 뒤쪽 = 큰 엔진음
- 좌석 등급: Economy / Business / First (회원 등급으로 해금, First는 더 조용함)

### 3.7 기종 & 항공사
- 기종은 거리 기준: 단거리 A320/737급, 중거리 787/A330급, 장거리 A350/777급
- 항공사는 **국가별 가상 항공사** (실제 항공사 이름/로고 금지 — 상표 문제)

### 3.8 안내방송 (영어)
탑승 → 환영 → 안전 안내(짧게) → 이륙 → 순항 중 기장 방송(가끔) → 안전벨트 차임(가끔) → 기내식(휴식) → 하강 → 착륙 → "Welcome to Seoul, local time is …"
- 고품질 TTS로 미리 녹음한 조각 + 도시 이름 조각을 이어붙임
- 볼륨 분리: 기내 소음 / 방송 / 차임. 방송 끄기 옵션

### 3.9 엄격 모드 (기본 ON)
- **모바일**: 앱을 벗어나면 1분 유예 → 초과 시 **회항(Diverted)**, 보상 없음
  - 화면 끄기(잠금)는 이탈 아님
  - 전화 수신은 예외
  - 유예 중 표시: 헤드업 알림 + 카운트다운, Android 16+ 라이브 업데이트(상태바 칩)
  - 옵션: "다른 앱 위에 표시" 권한으로 플로팅 알약 (다이나믹 아일랜드 느낌)
  - iOS: Live Activity + Dynamic Island (iOS 단계에서)
- **Windows**: 창 전환은 허용. 앱 종료/비행 포기만 회항
- 일시정지 모드는 옵션

### 3.10 비행 중 표시
- 비행 중 상시 알림: "ICN → PEK · 1:12:30 left" + 진행 바 (Android 포그라운드 서비스)

## 4. 탑승권

- 비행 시작 직전 발급. 항공사, 편명, 출발/도착 코드, 좌석, 게이트, 집중 시간, 승객 이름 + 등급 배지
- **스텁을 끌어서 뜯으면 비행 시작** (모바일: 드래그 + 햅틱 / PC: 드래그 또는 클릭)
- 회원 등급별 디자인

| 등급 | 탑승권 |
|---|---|
| Basic | 기본 종이 |
| Silver | 은박 띠 |
| Gold | 금박 띠 + 기울이면 반짝임 |
| Platinum | 검정 메탈 카드 + 뜯을 때 홀로그램 |

## 5. 보상: 스티커

### 5.1 종류 (실제 공항 기준)
| 종류 | 획득 |
|---|---|
| 수하물 태그 스텁 (감열지, 목적지 코드, 바코드, 태그번호) | 매 비행 기본 보상 |
| 손잡이 루프 태그 | 최근 비행 1개만 손잡이에 걸림. 다음 비행 시 제거, 몸통엔 스텁만 남음 |
| Priority / First | 비즈니스·퍼스트석 또는 Gold 이상 |
| 보안검색 스티커 | 국가별 언어/디자인 (예: 已安检, 検査済) |
| Transfer | 경유 비행 |
| Fragile / Heavy | 랜덤 레어 |

### 5.2 실사 표현
- 레이어: 디자인(코드/바코드/띠) + 실사 재질(CC0 종이·구김·때) + 3D 요철/광택 맵
- **에이징**: 오래된 스티커는 바래고, 귀퉁이 찢어지고, 떼어진 자국이 남음
- 3D 캐리어 위에 **데칼**로 투영 → 조명 받아 감열지 광택이 보임
- 실제 항공사 태그 사진/로고 사용 금지. 공항 IATA 코드는 실제 코드 사용

## 6. 캐리어

- 첫 실행 시 기본 캐리어 1개 무료 지급
- 3D, 손가락으로 회전/확대
- 활성 캐리어 1개에 스티커가 붙음. 용량이 차면 "완성" → 수하물 벨트 컬렉션
- 컬렉션 목록은 3D 스냅샷 썸네일 사용 (성능)

### 6.1 3D 모델
- **현재: 코드로 만든 임시 캐리어**로 개발 진행
- **추후 소스 우선순위: 1) 오픈소스** (Sketchfab CC0/CC-BY, Poly Haven 등 — 라이선스·출처 표기 기록 필수) **2) ComfyUI 직접 생성** (TRELLIS 등 MIT 계열. Hunyuan3D는 한국·EU·영국 제외 조항이 있어 사용 안 함)
- 베이스 모델 4~6종 × 재질/색상 변형으로 수십 종
- 모델 규격: 실제 크기(m), 바닥 중앙 원점, 정면 +Z, ≤50k 삼각형, 몸체 재질 분리, 텍스처 2K → 압축 1K, GLB + meshopt/KTX2

### 6.2 성능 원칙
- 비행 화면에서는 3D 렌더링 정지 (2D 지도만)
- 3D는 보관함, 스티커 부착 연출, 면세점에서만. 필요할 때만 렌더(on-demand)

## 7. 경제: 마일리지 & 면세점

- 마일 = 비행 거리 (km × 0.621). 집중 1시간 ≈ 350~500마일
- 관광 비행: 분당 5마일
- **면세점 (Duty Free)**: 마일로 캐리어 구매. 3D 회전 진열대
  - 도시 한정: 현재 위치가 그 도시일 때만 구매 가능
  - 등급 한정 / 시즌 한정
- 가격 기준(초안): 일반 5,000 / 고급 20,000 / 전설 100,000
- 가챠 없음, 현금 결제 없음

## 9. 지도 & 화면

- 비행 화면: NASA Blue Marble(낮) + Black Marble(밤 도시 불빛)을 실시간 낮/밤 경계선으로 합성
  - 구현: WebGL로 두 이미지를 지구본에 투영하고 태양 위치로 픽셀마다 낮/밤 혼합 (4096×2048, 합계 1.6MB). WebGL이 없으면 벡터 지구본으로 대체
  - 짧은 비행은 확대가 커서 다소 흐릿함 → 추후 고해상도 타일 검토
- 대권항로 곡선 + 비행기 아이콘 진행
- 기내 모니터 스타일 정보: 고도, 속도, 남은 시간, 도착 현지 시각
- 추후: 창가 뷰

### 화면 목록
| 화면 | 내용 |
|---|---|
| Onboarding | 이름 입력, 첫 캐리어 받기 |
| Home (Fly) | 현재 위치, 활성 캐리어, 예약 버튼 |
| Booking | 목적지 먼저 / 시간 먼저 |
| Check-in | 좌석 선택 |
| Boarding pass | 탑승권, 스텁 뜯기 |
| Flight | 지도, 진행, 소음 |
| Arrival | 착륙, 스티커 부착 연출, 마일 |
| Luggage | 캐리어 보관함 (3D) |
| Duty Free | 면세점 |
| Passport | 방문 국가 도장, 통계 |
